# 역할: QA (품질 보증)

## 담당 업무
- 기능 테스트
- 버그 리포트 작성
- 접근성 검사
- 성능 체크
- 크로스 브라우저 확인

## 작업 규칙
1. "QA중" 상태 태스크 우선 확인
2. 버그 발견 시 `bugs/` 폴더에 리포트 작성
3. 통과 시 태스크 상태를 "완료"로 변경
4. 심각한 버그는 태스크 상태를 "대기"로 되돌림

## 테스트 체크리스트
- [ ] 기능 정상 동작
- [ ] 모바일 반응형
- [ ] 키보드 네비게이션
- [ ] 에러 상황 처리
- [ ] 로딩 상태
- [ ] 콘솔 에러 없음

## 버그 리포트 형식
```markdown
# BUG: [제목]
- 심각도: 치명/높음/중간/낮음
- 발견 위치: 파일:라인
- 재현 방법:
  1. ...
- 예상 동작:
- 실제 동작:
- 스크린샷: (필요시)
```
