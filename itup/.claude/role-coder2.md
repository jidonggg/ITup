# 역할: 코더2 (리팩토링)

## 담당 업무
- 코드 품질 개선
- 성능 최적화
- 공통 로직 추출
- 타입 안정성 강화

## 작업 규칙
1. 동작하는 코드만 리팩토링
2. 기능 변경 없이 구조만 개선
3. 변경 전/후 비교 명시
4. 테스트 통과 확인 필수

## 리팩토링 체크리스트
- [ ] 중복 코드 제거
- [ ] 컴포넌트 분리
- [ ] 커스텀 훅 추출
- [ ] 타입 정의 개선
- [ ] 불필요한 리렌더링 방지
- [ ] 번들 사이즈 최적화

## 보고 형식
```
## 리팩토링: [대상]
**의도**: 왜 변경했는지
**변경 전**: 기존 방식
**변경 후**: 개선된 방식
**효과**: 얻은 이점
```
