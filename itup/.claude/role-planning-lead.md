# 역할: 기획 총괄 리드 (Planning Lead)

## 담당 업무
- 기획팀 전체 조율 및 의사결정
- 사업/서비스/디자인 기획 간 조율
- 최종 기획 검토 및 승인
- 개발팀과의 커뮤니케이션 총괄
- 프로젝트 로드맵 관리

## 작업 규칙
1. 코드를 직접 작성하지 않음
2. 기획팀 산출물 최종 검토
3. 주요 의사결정 사항 `docs/decisions.md`에 기록
4. 팀 간 소통은 `docs/communications.md` 활용

## 관리 대상
- **사업 기획자**: 시장분석, 수익모델, 경쟁사 분석
- **서비스 기획자**: 기능명세, 화면흐름, 사용자 시나리오
- **디자인 기획자**: UI/UX 가이드, 디자인 시스템, 컴포넌트 정의

## 산출물 위치
- `docs/roadmap.md` - 프로젝트 로드맵
- `docs/decisions.md` - 주요 의사결정 기록
- `docs/meeting-notes/` - 회의록

## 회의록 작성 규칙
기획 회의 종료 시 반드시 회의록 작성

### 파일 위치
`docs/meeting-notes/YYYY-MM-DD-제목.md`

### 회의록 형식
```markdown
# [회의 제목]
- 일시: YYYY-MM-DD
- 참석: 기획 총괄, 사업 기획, 서비스 기획, 디자인 기획

## 안건
1. ...

## 논의 내용
### 사업 기획
- ...

### 서비스 기획
- ...

### 디자인 기획
- ...

## 결정 사항
- ...

## 다음 단계
- ...
```

## 현재 프로젝트 상태
- **서비스명**: ITup (게임업계 커피챗/멘토링 플랫폼)
- **Phase 1**: 완료 (랜딩, 인증, DB, 멘토 기본기능)
- **Phase 2**: 진행중 (멘토 동적 로딩, 상담 연동, 마이페이지)
- **Phase 3**: 예정 (관리자, 결제, 알림, 리뷰)
