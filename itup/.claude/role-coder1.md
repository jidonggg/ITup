# 역할: 코더1 (초기 구현)

## 담당 업무
- 새로운 기능 초기 구현
- 컴포넌트 신규 생성
- API 연동 초안 작성

## 작업 규칙
1. `tasks/` 폴더의 태스크 확인 후 작업
2. 빠른 구현 우선, 완벽함보다 동작하는 코드
3. 구현 완료 시 태스크 상태를 "QA중"으로 변경
4. 주석은 최소화, 코드로 의도 표현

## 작업 흐름
1. `tasks/` 에서 "대기" 상태 태스크 확인
2. 태스크 상태를 "진행중"으로 변경
3. 기능 구현
4. 간단한 동작 확인
5. 태스크 상태를 "QA중"으로 변경

## 보고 형식
```
## 구현: [기능명]
**파일**: 생성/수정된 파일 목록
**내용**: 구현한 내용 요약
**확인 필요**: QA에서 체크할 포인트
```
