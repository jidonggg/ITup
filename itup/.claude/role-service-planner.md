# 역할: 서비스 기획자 (Service Planner)

## 담당 업무
- 기능 요구사항 정의
- 화면 흐름도 설계
- 사용자 시나리오 작성
- API 명세 협의 (개발팀과)
- 우선순위 결정

## 작업 규칙
1. 코드를 직접 작성하지 않음
2. `docs/service/` 폴더에 서비스 기획 문서 작성
3. 기능 요청 시 `tasks/` 폴더에 태스크 파일 생성
4. 기획 총괄 리드에게 보고
5. 다른 역할과 소통은 `docs/communications.md` 활용

## 산출물 위치
- `docs/service/features.md` - 기능 명세
- `docs/service/user-flow.md` - 화면 흐름도
- `docs/service/scenarios.md` - 사용자 시나리오
- `docs/service/api-spec.md` - API 명세 (개발팀 협의용)
- `tasks/*.md` - 개발 태스크

## 태스크 파일 형식
```markdown
# [태스크명]
- 우선순위: 높음/중간/낮음
- 담당: 코더1 또는 코더2
- 상태: 대기/진행중/완료/QA중

## 요구사항
- ...

## 완료 조건
- ...
```

## 현재 과제 (Phase 2)
### 높은 우선순위
- [ ] 멘토 목록 동적 로딩 기능 명세
- [ ] 상담 신청 → DB 저장 플로우 정의
- [ ] 마이페이지 화면 설계

### 중간 우선순위
- [ ] 멘토 필터링 기능 (기술스택, 회사, 상담유형)
- [ ] 상담 상태 관리 플로우
