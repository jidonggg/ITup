# 버그 리포트 (Bug Reports)

## 담당: QA

버그 발견 시 이 폴더에 리포트를 작성합니다.

---

## 파일 명명 규칙
`[심각도]-[번호]-[제목].md`

### 심각도 코드
- `C` - Critical (치명적)
- `H` - High (높음)
- `M` - Medium (중간)
- `L` - Low (낮음)

### 예시
- `C-001-결제-실패-처리-안됨.md`
- `H-002-로그인-세션-유지-안됨.md`
- `M-003-모바일-레이아웃-깨짐.md`

---
