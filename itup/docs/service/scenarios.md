## 1. 페르소나

### 1.1 멘티 - 김취준 (26세)
- **배경**: 게임 개발자 취업 준비생
- **목표**: 현직자에게 포트폴리오 피드백 받기
- **니즈**: 저렴한 가격, 신뢰할 수 있는 멘토

### 1.2 멘토 - 이현직 (32세)
- **배경**: 대형 게임사 5년차 프로그래머
- **목표**: 후배 양성, 부수입
- **니즈**: 간편한 스케줄 관리

## 2. 시나리오

### 2.1 시나리오 A: 첫 상담 신청

**사용자**: 김취준 (멘티)
**상황**: 처음 방문, 포트폴리오 피드백 받고 싶음

#### 흐름
1. **랜딩 페이지 도착**
   - Hero 섹션에서 서비스 이해
   - "멘토 둘러보기" 클릭

2. **멘토 탐색**
   - 멘토 섹션으로 스크롤
   - 원하는 분야 멘토 발견
   - 멘토 카드 클릭

3. **멘토 상세 확인**
   - 경력, 전문 분야 확인
   - "상담 신청" 클릭

4. **로그인 필요**
   - 로그인 모달 표시
   - "회원가입" 선택
   - 이메일/비밀번호 입력
   - 이메일 인증 완료

5. **상담 신청**
   - 상담 신청 모달
   - 이름, 연락처 자동 입력됨
   - 상담 내용 작성
   - "신청하기" 클릭

6. **결제**
   - 토스페이먼츠 결제창
   - 카드 결제 완료

7. **완료**
   - 성공 화면
   - 마이페이지에서 확인 가능

---

### 2.2 시나리오 B: 멘토 등록

**사용자**: 이현직 (멘토)
**상황**: 멘토로 활동하고 싶음

#### 흐름
1. **랜딩 페이지**
   - "멘토 등록" 버튼 클릭

2. **로그인**
   - 이미 회원인 경우 로그인
   - 비회원인 경우 회원가입

3. **멘토 등록 페이지**
   - /mentor/register 이동
   - 프로필 정보 입력
     - 회사, 직무, 경력
     - 상담 가능 분야
     - 가격 설정

4. **제출**
   - 등록 신청 완료
   - 승인 대기 안내

5. **승인 후**
   - 이메일 알림 (예정)
   - 멘토 대시보드 접근 가능

---

### 2.3 시나리오 C: 상담 관리 (멘토)

**사용자**: 이현직 (멘토)
**상황**: 신청된 상담 확인 및 관리

#### 흐름
1. **로그인 후**
   - 헤더에서 "대시보드" 클릭

2. **멘토 대시보드**
   - 신규 상담 신청 확인
   - 일정 확인

3. **상담 처리**
   - 상담 수락/거절
   - 일정 조율

---

### 2.4 시나리오 D: 비밀번호 찾기

**사용자**: 김취준 (멘티)
**상황**: 비밀번호를 잊어버림

#### 흐름
1. **로그인 모달**
   - "비밀번호를 잊으셨나요?" 클릭

2. **비밀번호 찾기 모달**
   - 이메일 입력
   - "재설정 링크 보내기" 클릭

3. **이메일 확인**
   - 재설정 링크 클릭

4. **비밀번호 재설정**
   - /auth/reset-password
   - 새 비밀번호 입력
   - 완료

## 3. 예외 시나리오

### 3.1 결제 실패
- **상황**: 카드 한도 초과
- **대응**: /payment/fail 페이지에서 재시도 안내

### 3.2 중복 가입 시도
- **상황**: 이미 가입된 이메일
- **대응**: 에러 메시지 + 로그인 유도

### 3.3 멘토 승인 거부
- **상황**: 정보 불충분
- **대응**: 거부 사유 안내 (예정)
