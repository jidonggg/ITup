## 2. 핵심 시나리오

### 2.1 시나리오 A: 첫 상담 신청 (취준생)

**사용자**: 김취준 (페르소나 A)
**상황**: 처음 ITup 방문, 포트폴리오 피드백 필요
**목표**: 현직 개발자에게 포트폴리오 리뷰 상담 신청

#### 상세 흐름

**Step 1: 서비스 발견**
```
- 게임잡 커뮤니티에서 ITup 광고 클릭
- 랜딩 페이지 도착
- Hero 섹션에서 "게임업계 현직자 멘토링" 확인
- "멘토 둘러보기" 클릭
```

**Step 2: 멘토 탐색**
```
- 멘토 섹션으로 스크롤
- 여러 멘토 카드 확인
- "클라이언트 개발" 태그가 있는 멘토 발견
- 멘토 카드 클릭
```

**Step 3: 멘토 상세 확인**
```
- 멘토 상세 모달 열림
- 경력 확인: "넥슨 5년차 클라이언트 프로그래머"
- 전문 분야: Unity, 포트폴리오 리뷰
- 가격: 30분 50,000원
- "상담 신청" 버튼 클릭
```

**Step 4: 로그인 필요**
```
- 로그인 모달 표시
- "아직 회원이 아니신가요?" → 회원가입 클릭
- 이메일, 비밀번호, 이름 입력
- 가입 완료, 이메일 인증 안내
- 이메일 인증 후 자동 로그인
```

**Step 5: 상담 신청**
```
- 상담 신청 모달 열림
- 이름, 이메일 자동 입력됨
- 전화번호 입력: 010-1234-5678 (자동 포맷팅)
- 상담 내용: "Unity 포트폴리오 리뷰 부탁드립니다.
              지금까지 만든 게임 3개 피드백 받고 싶습니다."
- 희망 일시: "이번 주 토요일 오후 2시"
- "신청하기" 클릭
```

**Step 6: 결제**
```
- 토스페이먼츠 결제창 열림
- 결제 금액: 50,000원
- 카드 결제 진행
- 결제 완료
```

**Step 7: 완료**
```
- /payment/success 페이지
- "상담 신청이 완료되었습니다!"
- "마이페이지에서 상담 현황을 확인하세요"
- 확인 이메일 수신
```

### 2.2 시나리오 B: 멘토 등록 (현직자)

**사용자**: 최현직 (페르소나 D)
**상황**: 멘토로 활동하고 싶음
**목표**: 멘토 등록 신청

#### 상세 흐름

**Step 1: 서비스 접속**
```
- 지인 추천으로 ITup 방문
- 랜딩 페이지에서 "멘토 등록" 버튼 클릭
```

**Step 2: 로그인**
```
- 기존 회원이므로 로그인 선택
- 이메일/비밀번호 입력
- 로그인 완료
- /mentor/register 페이지로 이동
```

**Step 3: 멘토 정보 입력**
```
- 회사: "넥슨코리아"
- 직무: "서버 프로그래머"
- 경력: "5년"
- 전문 분야: [서버 개발] [C++] [MMORPG] (태그 선택)
- 상담 가격: 50,000원 (30분)
- 자기소개:
  "안녕하세요, 넥슨에서 MMORPG 서버를 개발하고 있는 5년차 개발자입니다.
   게임 서버 개발에 관심 있는 분들에게 도움을 드리고 싶습니다.
   취업 면접, 포트폴리오 피드백, 실무 궁금증 등 편하게 물어보세요!"
```

**Step 4: 제출**
```
- "등록 신청" 버튼 클릭
- "멘토 등록 신청이 완료되었습니다."
- "관리자 검토 후 승인되면 이메일로 안내드립니다."
```

**Step 5: 승인 후**
```
- (1~2일 후) 승인 이메일 수신
- 로그인 시 Header에 "대시보드" 메뉴 표시
- /mentor/dashboard 접근 가능
- 멘토 목록에 프로필 표시
```

### 2.3 시나리오 C: 상담 관리 (멘토)

**사용자**: 최현직 (멘토)
**상황**: 상담 신청이 들어옴
**목표**: 상담 신청 확인 및 수락

#### 상세 흐름

**Step 1: 알림 수신**
```
- 이메일 알림 수신 (향후 구현)
- "새로운 상담 신청이 있습니다"
```

**Step 2: 대시보드 접속**
```
- ITup 로그인
- Header "대시보드" 클릭
- /mentor/dashboard 이동
```

**Step 3: 상담 신청 확인**
```
- 신규 상담 신청 목록 확인
- 신청자: 김취준
- 상담 내용: "Unity 포트폴리오 리뷰..."
- 희망 일시: "토요일 오후 2시"
```

**Step 4: 상담 수락**
```
- [수락] 버튼 클릭
- 상담 일정 확정
- 멘티에게 확정 알림 발송 (향후)
```

---

### 2.4 시나리오 D: 비밀번호 찾기

**사용자**: 김취준
**상황**: 비밀번호를 잊어버림
**목표**: 비밀번호 재설정

#### 상세 흐름

**Step 1: 로그인 시도**
```
- 로그인 모달에서 로그인 시도
- 비밀번호 오류
- "비밀번호를 잊으셨나요?" 클릭
```

**Step 2: 이메일 입력**
```
- 비밀번호 찾기 모달 열림
- 가입한 이메일 입력
- "재설정 링크 보내기" 클릭
- "이메일을 확인해주세요" 메시지
```

**Step 3: 이메일 확인**
```
- 이메일 수신
- "비밀번호 재설정" 링크 클릭
- /auth/reset-password 페이지 이동
```

**Step 4: 비밀번호 재설정**
```
- 새 비밀번호 입력
- 비밀번호 확인 입력
- "비밀번호 변경" 클릭
- "비밀번호가 변경되었습니다"
- 로그인 페이지로 이동
```

### 2.5 시나리오 E: 관리자 멘토 승인

**사용자**: 관리자
**상황**: 새로운 멘토 등록 신청 접수
**목표**: 멘토 심사 및 승인

#### 상세 흐름

**Step 1: 관리자 접속**
```
- 관리자 계정으로 로그인
- /admin 대시보드 이동
```

**Step 2: 대기 멘토 확인**
```
- "멘토 관리" 섹션 확인
- 대기중 멘토: 최현직 (넥슨 5년차)
- 상세 정보 확인 클릭
```

**Step 3: 심사**
```
- 회사: 넥슨코리아 ✓
- 직무: 서버 프로그래머 ✓
- 경력: 5년 ✓
- 자기소개: 적절함 ✓
```

**Step 4: 승인**
```
- [승인] 버튼 클릭
- "멘토가 승인되었습니다"
- 멘토에게 승인 알림 발송
- 멘토 목록에 표시 시작
```

## 3. 예외 시나리오

### 3.1 결제 실패

**상황**: 카드 한도 초과
```
결제 진행
    ↓
카드사 거절
    ↓
/payment/fail 페이지
    ↓
"결제에 실패했습니다. 다른 결제 수단을 이용해주세요."
    ↓
[다시 시도] 또는 [홈으로]
```

### 3.2 중복 가입 시도

**상황**: 이미 가입된 이메일로 회원가입 시도
```
회원가입 시도
    ↓
"이미 가입된 이메일입니다"
    ↓
로그인 유도
```

### 3.3 멘토 승인 거부

**상황**: 정보 불충분
```
멘토 등록 신청
    ↓
관리자 검토
    ↓
정보 불충분 (자기소개 너무 짧음)
    ↓
[거부] 클릭
    ↓
거부 사유 입력 (향후 구현)
    ↓
멘토에게 거부 사유 안내 이메일
```

### 3.4 상담 취소

**상황**: 멘티가 상담 24시간 전 취소
```
마이페이지 → 상담 내역
    ↓
[취소] 버튼 클릭
    ↓
"정말 취소하시겠습니까?"
    ↓
[확인]
    ↓
100% 환불 처리
    ↓
멘토에게 취소 알림
```

## 4. 성공 지표

### 4.1 시나리오별 전환율 목표

| 시나리오 | 시작 → 완료 | 목표 전환율 |
|----------|-------------|------------|
| 첫 상담 신청 | 랜딩 → 결제 완료 | 5% |
| 멘토 등록 | 등록 페이지 → 제출 | 60% |
| 비밀번호 찾기 | 링크 클릭 → 재설정 완료 | 80% |

### 4.2 이탈 포인트 분석

| 단계 | 예상 이탈 원인 | 개선 방안 |
|------|---------------|----------|
| 회원가입 | 복잡한 절차 | 소셜 로그인 추가 |
| 결제 | 가격 부담 | 첫 상담 할인 |
| 상담 신청 | 정보 입력 번거로움 | 자동 입력 확대 |
