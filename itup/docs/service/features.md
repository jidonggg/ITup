## 2. 사용자 기능 상세

### 2.1 U-01: 회원가입/로그인

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 사용자 인증 및 계정 생성 |
| 사용자 | 모든 방문자 |
| 위치 | Header → 로그인/회원가입 버튼 |

#### 기능 요구사항
| ID | 요구사항 | 우선순위 | 상태 |
|----|----------|----------|------|
| U-01-1 | 이메일/비밀번호 회원가입 | 높음 | 완료 |
| U-01-2 | 비밀번호 6자 이상 검증 | 높음 | 완료 |
| U-01-3 | 비밀번호 확인 일치 검증 | 높음 | 완료 |
| U-01-4 | 중복 이메일 에러 처리 | 높음 | 완료 |
| U-01-5 | 이메일 인증 안내 | 중간 | 완료 |
| U-01-6 | 로그인 유지 | 중간 | 완료 |

#### 입력/출력
- **입력**: 이메일, 비밀번호, 비밀번호 확인, 이름
- **출력**: 인증 토큰, 사용자 세션

#### UI 요소
- 모달: SignupModal, LoginModal
- 버튼: 로그인, 회원가입, 소셜 로그인 (향후)
- 폼 필드: 이메일, 비밀번호, 이름

#### 예외 처리
| 상황 | 처리 |
|------|------|
| 중복 이메일 | "이미 가입된 이메일입니다" 메시지 |
| 잘못된 비밀번호 | "비밀번호가 일치하지 않습니다" 메시지 |
| 네트워크 오류 | "잠시 후 다시 시도해주세요" 메시지 |

## 3. 멘토 기능 상세

### 3.1 M-01: 멘토 등록

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 멘토로 활동 신청 |
| 사용자 | 로그인한 사용자 |
| 위치 | /mentor/register |

#### 입력 필드
| 필드 | 필수 | 설명 |
|------|------|------|
| 회사 | O | 현재/최근 재직 회사 |
| 직무 | O | 기획, 프로그래머, 아티스트 등 |
| 경력 | O | 연차 |
| 전문 분야 | O | 태그 형태 |
| 상담 가격 | O | 30분 기준 |
| 자기소개 | O | 500자 이내 |
| 프로필 이미지 | - | 선택 |

#### 등록 후 흐름
1. 등록 신청 제출
2. 관리자 검토 대기
3. 승인 시 멘토 목록에 표시
4. 거부 시 사유 안내 (향후)

---

#### 개요
| 항목 | 내용 |

| 수익 현황 | 정산 예정 금액 (향후) |
