---

## 1. 전체 사이트맵

```
/ (랜딩)
├── /mentors (멘토 목록)
├── /mypage (마이페이지)
│   ├── 프로필 탭
│   ├── 상담 내역 탭
│   ├── 결제 내역 탭
│   └── 구독 관리 탭
├── /faq (FAQ)
├── /terms (이용약관)
├── /privacy (개인정보처리방침)
│
├── /mentor
│   ├── /register (멘토 등록)
│   └── /dashboard (멘토 대시보드)
│
├── /admin (관리자 대시보드)
│
├── /payment
│   ├── /success (결제 성공)
│   └── /fail (결제 실패)
│
└── /auth
    ├── /callback (OAuth 콜백)
    └── /reset-password (비밀번호 재설정)
```

## 3. 모달 흐름

### 3.1 모달 전환 관계

```
                    ┌──────────────┐
                    │  로그인 모달  │
                    └──────────────┘
                     ↑            ↓
            "로그인" 링크    "회원가입" 링크
                     ↑            ↓
                    ┌──────────────┐
                    │ 회원가입 모달 │
                    └──────────────┘

                    ┌──────────────┐
     "비밀번호 찾기" │ 비밀번호     │
         ──────────→│ 찾기 모달    │
                    └──────────────┘

                    ┌──────────────┐
     멘토 카드 클릭  │ 멘토 상세    │  "상담 신청"   ┌──────────────┐
         ──────────→│ 모달        │ ────────────→│ 상담 신청    │
                    └──────────────┘               │ 모달        │
                                                   └──────────────┘
```

### 3.2 모달 공통 동작

| 동작 | 설명 |
|------|------|
| ESC 키 | 모달 닫기 |
| 외부 클릭 | 모달 닫기 |
| X 버튼 | 모달 닫기 |
| 바디 스크롤 | 잠금 (모달 열림 시) |

## 4. 에러/예외 흐름

### 4.1 결제 실패

```
결제 진행 중
    │
    └─[결제 실패]──→ /payment/fail
                        │
                        ▼
                   ┌──────────────┐
                   │ 결제 실패 안내 │
                   │              │
                   │ [다시 시도]   │
                   │ [홈으로]      │
                   └──────────────┘
```

### 4.2 인증 만료

```
페이지 접근/API 호출
    │
    └─[401 Unauthorized]──→ AuthContext 감지
                                │
                                ▼
                          로그인 모달 표시
```

### 4.3 권한 없음

```
/admin, /mentor/dashboard 접근
    │
    └─[권한 없음]──→ 메인 페이지 리다이렉트
                    또는 에러 메시지
```

## 5. 반응형 분기

### 5.1 브레이크포인트

| 화면 | 사이즈 | Tailwind |
|------|--------|----------|
| Mobile | < 640px | default |
| Tablet | 640px+ | sm: |
| Desktop | 1024px+ | lg: |
| Wide | 1280px+ | xl: |

### 5.2 컴포넌트별 반응형

| 컴포넌트 | 모바일 | 데스크톱 |
|----------|--------|----------|
| Header | 햄버거 메뉴 | 네비게이션 바 |
| 멘토 카드 | 1열 그리드 | 3열 그리드 |
| 모달 | 전체 화면 | 중앙 팝업 |
| Footer | 세로 배치 | 가로 배치 |
| 마이페이지 탭 | 가로 스크롤 | 고정 탭 |

## 6. 네비게이션 구조

### 6.1 Header 네비게이션

**비로그인 상태**
```
[로고] ─────── [멘토 둘러보기] [FAQ] ─────── [로그인] [회원가입]
```

**로그인 상태 (일반 사용자)**
```
[로고] ─────── [멘토 둘러보기] [FAQ] ─────── [마이페이지] [로그아웃]
```

**로그인 상태 (멘토)**
```
[로고] ─────── [멘토 둘러보기] [FAQ] ─────── [대시보드] [마이페이지] [로그아웃]
```

**로그인 상태 (관리자)**
```
[로고] ─────── [멘토 둘러보기] [FAQ] ─────── [관리자] [마이페이지] [로그아웃]
```
