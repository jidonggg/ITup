# 화면 흐름도 (User Flow)

> 최종 업데이트: YYYY-MM-DD

---

## 1. 전체 사이트맵

```
/ (랜딩)
├── /mentors (멘토 목록)
├── /mypage (마이페이지)
├── /faq (FAQ)
├── /terms (이용약관)
├── /privacy (개인정보처리방침)
├── /mentor
│   ├── /register (멘토 등록)
│   └── /dashboard (멘토 대시보드)
├── /admin (관리자)
├── /payment
│   ├── /success (결제 성공)
│   └── /fail (결제 실패)
└── /auth
    ├── /callback (OAuth)
    └── /reset-password (비밀번호 재설정)
```

---

## 2. 주요 사용자 흐름

### 2.1 멘티 - 상담 신청 흐름
```
랜딩 페이지
    │
    ├─[비로그인]─→ 로그인 모달 → 회원가입/로그인
    │
    └─[로그인됨]─→ 멘토 섹션/목록
                      │
                      └─→ 멘토 카드 클릭
                            │
                            └─→ 멘토 상세 모달
                                  │
                                  └─→ "상담 신청" 클릭
                                        │
                                        └─→ 상담 신청 모달
                                              │
                                              └─→ 정보 입력 → 결제
                                                              │
                                                              └─→ 완료
```

### 2.2 멘토 - 등록 흐름
```
랜딩 페이지
    │
    └─→ "멘토 등록" 클릭
          │
          ├─[비로그인]─→ 로그인 유도
          │
          └─[로그인됨]─→ /mentor/register
                            │
                            └─→ 폼 작성 → 제출
                                          │
                                          └─→ 승인 대기
```

### 2.3 관리자 - 멘토 승인 흐름
```
/admin
    │
    └─→ 멘토 관리 탭
          │
          └─→ 대기 중 멘토 목록
                │
                └─→ 승인/거부
```

---

## 3. 모달 흐름

### 3.1 인증 모달
```
Header "로그인" 클릭
    │
    └─→ 로그인 모달
          │
          ├─→ "회원가입" 링크 → 회원가입 모달
          │
          └─→ "비밀번호 찾기" → 비밀번호 찾기 모달
```

### 3.2 상담 모달
```
멘토 상세 모달
    │
    └─→ "상담 신청" 클릭
          │
          └─→ 상담 신청 모달
                │
                └─→ 결제 진행
```

---

## 4. 에러 흐름

### 4.1 결제 실패
```
결제 진행
    │
    └─[실패]─→ /payment/fail
                  │
                  └─→ 재시도 / 홈으로
```

### 4.2 인증 만료
```
페이지 접근
    │
    └─[세션 만료]─→ 로그인 모달
```

## 5. 반응형 분기

| 화면 | 데스크톱 | 모바일 |

| 모달 | 중앙 팝업 | 전체 화면 |
