## 2. 네비게이션 수정 (우선순위: 높음)

### 2.1 Header 네비게이션 링크 수정

**현재 상태** (Header.tsx 38-43행):
```javascript
const navLinks = [
  { href: "#features", label: "특징" },
  { href: "#mentors", label: "멘토" },
  { href: "#testimonials", label: "후기" },
  { href: "#pricing", label: "요금" },
];
```

**기획 문서 (user-flow.md)**:
```
비로그인: [멘토 둘러보기] [FAQ]
로그인(일반): [멘토 둘러보기] [FAQ] [마이페이지]
로그인(멘토): [멘토 둘러보기] [FAQ] [대시보드] [마이페이지]
로그인(관리자): [멘토 둘러보기] [FAQ] [관리자] [마이페이지]
```

**변경 필요**:
- 앵커 링크(#) → 실제 페이지 링크(/)로 변경
- 로그인 상태/역할에 따른 동적 메뉴 표시
- FAQ 링크 추가

**담당**: 코더1 (구현)

## 3. 멘토 기능 보완 (우선순위: 높음)

### 3.1 멘토 상세 모달에 가격 표시 추가

**기획 문서 (features.md, scenarios.md)**:
- 멘토 상세에서 "상담 가격: 30분 50,000원" 표시
- 가격 정보 확인 후 상담 신청 진행

**현재 상태 (MentorDetailModal.tsx)**:
- 가격 정보 표시 없음
- MentorData 인터페이스에 price 필드 없음

**변경 필요**:
```typescript
// MentorData에 추가
price?: number;

// 모달에 가격 섹션 추가
<div className="mb-6">
  <h3>상담 가격</h3>
  <p>{mentor.price?.toLocaleString()}원 / 30분</p>
</div>
```

**담당**: 코더1 (구현)

### 3.2 멘토 그리드 열 수 조정

**기획 문서 (style-guide.md)**:
- 멘토 그리드: 데스크톱 3열

**현재 상태 (Mentors.tsx 102행)**:
```javascript
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6">
```

**변경 필요**:
```javascript
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
```

**담당**: 코더2 (리팩토링)

## 4. 상담 신청 흐름 개선 (우선순위: 중간)

### 4.1 결제 연동 흐름 추가

**기획 문서 (scenarios.md)**:
```
상담 신청 완료
    ↓
결제 진행 (토스페이먼츠)
    ↓
/payment/success 또는 /payment/fail
```

**현재 상태 (ConsultModal.tsx)**:
- "무료 상담 신청" 문구 사용
- 결제 없이 바로 신청 완료

**변경 필요**:
- 상담 신청 후 결제 페이지로 이동
- 또는 결제 모달 연동
- "무료 상담" → "상담 신청" 문구 변경 (유료 모델)

**담당**: 코더1 (구현)

## 5. 스타일 일관성 개선 (우선순위: 낮음)

### 5.1 Tailwind 클래스 표준화

**기획 문서 (style-guide.md)**에 정의된 표준 클래스:
- Primary Button: `bg-blue-600 hover:bg-blue-700 text-white font-semibold px-6 py-3 rounded-lg`
- Card: `bg-slate-800 rounded-xl p-6 shadow-lg`
- Input: `bg-slate-700 border border-slate-600 rounded-lg`

**현재 상태**:
- CSS 변수 사용 (`bg-primary`, `bg-card-bg`, `border-card-border`)
- ThemeContext를 통한 동적 테마

**확인 필요**:
- CSS 변수가 style-guide.md 색상과 일치하는지 확인
- 불일치 시 수정

**담당**: 코더2 (리팩토링)
