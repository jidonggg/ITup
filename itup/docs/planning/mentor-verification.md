# 멘토 인증 절차 기획

> 작성일: 2025-01-28
> 담당: 기획팀

---

## 1. 개요

멘토의 경력을 검증하여 신뢰성 있는 멘토링 서비스를 제공합니다.

---

## 2. 인증 방식

### 2.1 현재 직장 인증 - 회사 이메일

| 항목 | 내용 |
|------|------|
| 인증 방법 | 회사 도메인 이메일로 인증 코드 발송 |
| 처리 방식 | **자동 검증** |
| 예시 | `@nexon.com`, `@netmarble.com`, `@krafton.com` 등 |

**플로우:**
1. 멘토 등록 시 회사 이메일 입력
2. 해당 이메일로 6자리 인증 코드 발송
3. 코드 입력 시 자동 인증 완료
4. **인증 코드는 검증 즉시 폐기** (저장하지 않음)

### 2.2 이전 직장 인증 - 고용보험 취득내역

| 항목 | 내용 |
|------|------|
| 인증 방법 | 고용보험 피보험자격 취득내역서 제출 |
| 처리 방식 | **자동 검증 후 즉시 폐기** |
| 발급처 | 고용보험 홈페이지 또는 정부24 |

**플로우:**
1. 멘토 등록 시 고용보험 취득내역서 이미지/PDF 업로드
2. OCR을 통해 회사명, 취득일자 자동 추출
3. 입력된 이전 직장 정보와 대조
4. **검증 완료 즉시 원본 파일 및 추출 데이터 폐기**
5. 인증 결과(성공/실패)만 기록

---

## 3. 개인정보 보호

### 3.1 데이터 처리 원칙

| 원칙 | 내용 |
|------|------|
| 최소 수집 | 인증에 필요한 정보만 수집 |
| 즉시 폐기 | 검증 완료 후 원본 데이터 즉시 삭제 |
| 결과만 저장 | 인증 성공/실패 여부, 인증일시만 DB에 기록 |
| 암호화 전송 | 업로드 시 TLS 암호화 적용 |

### 3.2 저장하지 않는 정보

- 이메일 인증 코드
- 고용보험 취득내역서 원본 이미지/PDF
- OCR로 추출된 텍스트 데이터
- 주민등록번호 등 민감 정보

### 3.3 저장하는 정보

- 인증 완료 여부 (boolean)
- 인증 완료 일시 (timestamp)
- 인증 방법 (email/document)
- 인증된 회사명 (사용자 동의 하에)

## 4. 사용자 안내 문구

### 인증 페이지 안내

```
[개인정보 보호 안내]

제출하신 인증 서류는 자동 검증 후 즉시 폐기됩니다.
- 원본 파일: 검증 완료 즉시 삭제
- 추출 데이터: 검증 완료 즉시 삭제
- 저장 정보: 인증 완료 여부만 기록

ITup은 최소한의 정보만 수집하며,
인증 목적 외 다른 용도로 사용하지 않습니다.
```

## 5. 기술 구현 사항

### 5.1 이메일 인증

```typescript
// 인증 코드 생성 및 발송
const code = generateCode(); // 6자리 랜덤
await sendEmail(companyEmail, code);
// 코드는 메모리/캐시에만 임시 저장 (5분 TTL)

// 검증 완료 시
verifyCode(inputCode);
deleteCode(companyEmail); // 즉시 삭제
updateMentorVerification(mentorId, { verified: true });
```

### 5.2 고용보험 내역 인증

```typescript
// 파일 업로드 (임시 저장)
const tempPath = await uploadToTemp(file);

// OCR 검증
const result = await verifyDocument(tempPath);

// 즉시 폐기
await deleteFile(tempPath);

// 결과만 저장
await updateMentorVerification(mentorId, {
  verified: result.success,
  method: 'document'
});
```
