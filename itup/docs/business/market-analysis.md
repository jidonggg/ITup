## 1. 시장 개요

### 1.1 타겟 시장
- **1차 타겟**: 게임 업계 취업 준비생 (대학생, 취준생, 전직 희망자)
- **2차 타겟**: 게임 업계 현직자 (멘토 역할, 부수입 희망)

### 1.2 시장 규모

| TAM (전체 시장) | 한국 온라인 교육/멘토링 시장 약 5조원 | 추정 |
| SAM (유효 시장) | 커리어 멘토링 시장 약 500억원 | 추정 |

## 2. 시장 트렌드

### 2.1 성장 동인

1. **게임 업계 취업난 심화**
   - 대형 게임사 구조조정 연쇄 (컴투스, 넷마블, 엔씨소프트 등)
   - 경력직 선호로 신입 취업문 축소
   - 채용 경쟁률 100:1 이상 공고 다수
   > 출처: [디지털투데이](https://www.digitaltoday.co.kr/news/articleView.html?idxno=502952)

2. **현직자 조언 수요 증가**
   - 취업 정보 불균형 해소 니즈
   - 포트폴리오 피드백 수요
   - 실제 업무 환경 정보 희망

3. **커피챗 문화 확산**
   - IT/스타트업에서 게임 업계로 확산
   - 비공식 채용 채널로 활용

### 2.2 시장 기회: 경쟁사 서비스 종료

**커피챗(coffeechat.kr) 서비스 종료 (2025.02.07)**
- 시드 투자, TIPS 선정까지 받았으나 갑작스러운 종료
- 사용자/파트너 모두 대안 플랫폼 필요
- **시장 공백 발생 → ITup 진입 기회**

> 출처: [커피챗 서비스 종료 안내](https://redbusbagman.com/goodbyecoffeechat/)

### 2.3 진입 장벽

1. **양질의 멘토 확보 어려움**
   - 현직자 참여 유인 필요
   - 특정 멘토에 수요 집중 현상

2. **신뢰성 검증**
   - 멘토 경력/이력 검증 시스템 필요
   - 익명성 vs 실명성 균형

3. **수익화 모델 검증**
   - 무료 서비스(잇다) vs 유료 서비스(원티드) 경쟁

## 3. 타겟 고객 분석

### 3.1 멘티 페르소나

**페르소나 A: 김취준 (26세, 남)**
| 항목 | 내용 |
|------|------|
| 연령대 | 20대 중후반 |
| 직업 | 취업준비생 (게임 프로그래머 지망) |
| 학력 | 4년제 컴퓨터공학과 졸업 |
| 니즈 | 포트폴리오 피드백, 면접 팁, 회사 분위기 |
| 페인포인트 | 정보 부족, 불합격 연속, 멘토 접근 어려움 |
| 지불 의향 | 1회 상담 3~5만원 |

**페르소나 B: 이전직 (29세, 여)**
| 항목 | 내용 |
|------|------|
| 연령대 | 20대 후반 ~ 30대 초반 |
| 직업 | 타업종 3년차 (게임 기획자로 전직 희망) |
| 니즈 | 전직 가능성, 필요 스킬, 현실적 조언 |
| 페인포인트 | 업계 정보 부재, 네트워크 없음 |
| 지불 의향 | 1회 상담 5~10만원 |

## 5. 기회 및 위협

### 5.1 기회 (Opportunities)

1. **커피챗 서비스 종료로 시장 공백**
   - 기존 사용자/멘토 흡수 가능
   - 유료 1:1 상담 수요 존재 확인됨

2. **게임 업계 취업난 심화**
   - 멘토링 수요 증가
   - 정보 비대칭 해소 니즈

3. **게임업계 특화 플랫폼 부재**
   - 현재 게임업계만을 위한 멘토링 없음
   - 틈새시장 선점 기회

4. **정부 지원 프로그램 연계 가능**
   - 한국콘텐츠진흥원 게임인재원 등과 협력 가능성

### 5.2 위협 (Threats)

1. **게임 업계 불황 지속**
   - 멘토(현직자) 이탈 가능성
   - 취업 자체 감소로 수요 위축 가능

2. **무료 서비스와의 경쟁**
   - 잇다(무료) 대비 유료 정당화 필요

3. **대형 플랫폼 진입 가능성**
   - 원티드, 사람인 등이 게임 카테고리 강화 시

4. **멘토 수급 불균형**
   - 인기 멘토 쏠림 현상
   - 멘토 번아웃

## 6. 결론 및 시사점

### 6.1 시장 진입 타당성: **긍정적**

- 게임 시장 25조원, 지속 성장 중
- 취업난으로 멘토링 수요 증가
- 커피챗 종료로 시장 공백 발생
- 게임업계 특화 플랫폼은 현재 없음

### 6.2 핵심 성공 요인

1. **양질의 멘토 확보** - 대형 게임사 현직자 영입
2. **적정 가격 책정** - 무료(잇다)와 고가(원티드) 사이
3. **신뢰성 확보** - 멘토 검증 시스템
4. **커뮤니티 구축** - 단발성 상담 → 지속적 관계

### 6.3 권장 전략

- **Phase 1**: 무료/저가로 멘토-멘티 풀 확보
- **Phase 2**: 프리미엄 서비스 도입 (심층 상담, 이력서 첨삭)
- **Phase 3**: B2B 확장 (게임사 채용 연계)
