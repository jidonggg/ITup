## 1. 핵심 지표 (North Star Metric)

### **월간 완료 상담 수 (Monthly Completed Consultations)**

| 항목 | 내용 |
|------|------|
| 정의 | 월간 정상 완료된 1:1 상담 건수 |
| 측정 방법 | consultations 테이블 status='completed' 집계 |
| 목표 | Phase 1: 100건/월, Phase 2: 300건/월 |
| 측정 주기 | 주간/월간 |

**이유**: 상담 완료가 곧 매출이자 가치 창출의 핵심

## 2. 성장 지표 (Growth Metrics)

### 2.1 사용자 지표

| 지표 | 정의 | 현재 | 목표 (3개월) | 목표 (1년) |
|------|------|------|-------------|-----------|
| **MAU** | 월간 활성 사용자 | 0 | 500명 | 3,000명 |
| 신규 가입 | 월간 신규 회원 | 0 | 200명 | 500명 |
| 멘토 수 | 활성 멘토 수 | 0 | 20명 | 100명 |
| 멘티 수 | 상담 신청 멘티 수 | 0 | 100명 | 500명 |

### 2.2 전환 지표

| 지표 | 정의 | 현재 | 목표 |
|------|------|------|------|
| 가입→상담 전환율 | 가입 후 첫 상담 신청 비율 | - | **15%** |
| 상담 신청→완료율 | 신청 후 실제 완료 비율 | - | **80%** |
| 첫 상담→재상담율 | 첫 상담 후 재구매 비율 | - | **30%** |
| 멘토 등록→승인율 | 등록 후 승인 비율 | - | **50%** |

### 2.3 측정 방법

```sql
-- 가입→상담 전환율
SELECT
  COUNT(DISTINCT c.user_id) / COUNT(DISTINCT p.id) * 100
FROM profiles p
LEFT JOIN consultations c ON p.id = c.user_id
WHERE p.created_at >= '2025-01-01';

-- 재상담율
SELECT
  COUNT(DISTINCT user_id)
FROM consultations
WHERE user_id IN (
  SELECT user_id FROM consultations
  GROUP BY user_id HAVING COUNT(*) > 1
);
```

## 3. 매출 지표 (Revenue Metrics)

### 3.1 핵심 매출 지표

| 지표 | 정의 | 현재 | 목표 (3개월) | 목표 (1년) |
|------|------|------|-------------|-----------|
| **GMV** | 총 거래액 | 0 | 500만원/월 | 3,000만원/월 |
| 순매출 | 플랫폼 수익 (수수료) | 0 | 75만원/월 | 450만원/월 |
| ARPU | 사용자당 매출 | - | 50,000원 | 60,000원 |
| ARPPU | 결제 사용자당 매출 | - | 70,000원 | 85,000원 |

### 3.2 계산 공식

```
GMV = 완료 상담 수 × 평균 상담료
순매출 = GMV × 15% (플랫폼 수수료)
ARPU = GMV ÷ MAU
ARPPU = GMV ÷ 결제 사용자 수
```

### 3.3 매출 목표 로드맵

| 기간 | 월 상담 수 | 평균 단가 | 월 GMV | 월 순매출 |
|------|-----------|----------|--------|----------|
| 1~3개월 | 50건 | 50,000원 | 250만원 | 37.5만원 |
| 4~6개월 | 150건 | 55,000원 | 825만원 | 124만원 |
| 7~12개월 | 300건 | 60,000원 | 1,800만원 | 270만원 |

## 4. 품질 지표 (Quality Metrics)

### 4.1 만족도 지표

| 지표 | 정의 | 현재 | 목표 |
|------|------|------|------|
| 상담 만족도 | 상담 후 평균 별점 | - | **4.5/5.0** |
| NPS | 순추천지수 | - | **40+** |
| 리뷰 작성율 | 상담 후 리뷰 비율 | - | 50% |

### 4.2 리텐션 지표

| 지표 | 정의 | 현재 | 목표 |
|------|------|------|------|
| D7 리텐션 | 7일 후 재방문율 | - | 30% |
| D30 리텐션 | 30일 후 재방문율 | - | 20% |
| 월간 리텐션 | 월간 재구매율 | - | 25% |

### 4.3 측정 방법

```
NPS = 추천(9-10점) 비율 - 비추천(0-6점) 비율

NPS 해석:
- 70+ : 최고 수준
- 50-70 : 우수
- 30-50 : 양호
- 0-30 : 개선 필요
```
