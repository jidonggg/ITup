## 2. 상세 분석

### 2.1 커피챗 (Coffeechat) - **서비스 종료**

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 1:1 익명 음성 대화 기반 커리어 상담 |
| 타겟 고객 | 직장인, 취준생, 이직 희망자 |
| 출시 시기 | 2023년 |
| 종료일 | 2025년 2월 7일 |

#### 투자 현황
- 2023년 5월: 본엔젤스벤처파트너스 시드 투자
- 2023년 7월: TIPS 프로그램 최종 선정

#### 주요 고객사
당근, 토스증권, 리디, 한국신용데이터 등

#### 종료 사유 (추정)
- 멘토 수급 불균형
- 수익화 모델 검증 실패
- 특정 멘토 쏠림 현상

#### ITup 시사점
- **기회**: 유료 1:1 상담 시장 공백 발생
- **교훈**: 멘토 확보 전략, 수익 모델 검증 중요

> 출처: [커피챗 서비스 종료 안내](https://redbusbagman.com/goodbyecoffeechat/)

### 2.2 잇다 (itdaa)

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 실명 기반 현직자 1:1 텍스트 멘토링 |
| 타겟 고객 | 대학생, 취업준비생 |
| 출시 시기 | 2013년 |
| 운영사 | 레디앤스타트 |

#### 비즈니스 모델
| 구분 | 내용 |
|------|------|
| 멘티 비용 | **무료** (로켓 차감제) |
| 멘토 수익 | **없음** (재능기부) |
| 수익원 | B2B (대학, 지자체 제휴) |

#### 서비스 특징
- 2,700여 명 인증 현직자 멘토
- 실명/명함 검증 시스템
- 5일 이내 답변 보장
- 국내 30여개 대학, 서울시 등 지자체 제휴

#### 기능 비교
| 기능 | 잇다 | ITup |
|------|------|------|
| 상담 형태 | 텍스트 Q&A | 실시간 화상/음성 |
| 가격 | 무료 | 유료 |
| 멘토 보상 | 없음 | 수익 배분 |
| 업계 특화 | 전 업종 | 게임 특화 |
| 응답 시간 | 최대 5일 | 실시간 예약 |

#### 강점
- 무료 서비스로 접근성 높음
- 실명 기반 신뢰성
- 대학/지자체 제휴 네트워크

#### 약점
- 멘토 보상 없어 참여 유인 부족
- 텍스트 한정 (깊이 있는 상담 어려움)
- 응답 시간 최대 5일

> 출처: [잇다 위키백과](https://ko.wikipedia.org/wiki/%EC%86%8C%EC%85%9C%EB%A9%98%ED%86%A0%EB%A7%81_%EC%9E%87%EB%8B%A4)

### 2.3 원티드 커리어 코칭

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 1:1 커리어 상담 및 코칭 |
| 타겟 고객 | IT/스타트업 경력자, 이직 희망자 |
| 운영사 | 원티드랩 |

#### 가격 정책
| 서비스 유형 | 가격대 | 비고 |
|-------------|--------|------|
| 커리어 토크 | 3~10만원 | 멘토별 상이 |
| 이력서 코칭 | 5~15만원 | 멘토별 상이 |
| 포트폴리오 코칭 | 5~20만원 | 멘토별 상이 |
| 전문가 인터뷰 | 10~30만원 | 멘토별 상이 |
| 자문/컨설팅 | 협의 | 고가 |

#### 서비스 특징
- 300만 현직 전문가 풀
- 채용 연계 (합격 시 50만원 보상금)
- IT/스타트업 특화

#### 기능 비교
| 기능 | 원티드 | ITup |
|------|--------|------|
| 타겟 업계 | IT/스타트업 | 게임 |
| 가격대 | 고가 (5~30만원) | 중저가 (3~10만원) |
| 멘토 풀 | 300만명 | 게임업계 특화 |
| 채용 연계 | 강함 | 향후 예정 |

#### 강점
- 대규모 멘토 풀
- 채용 플랫폼과 연계
- 브랜드 인지도

#### 약점
- 게임 업계 멘토 부족
- 가격대 높음
- IT 외 업종 약함

> 출처: [원티드 커리어 코칭](https://www.wanted.co.kr/events/career_coaching)

### 2.4 링커리어

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 대외활동/채용 정보 + 멘토 게시판 |
| 타겟 고객 | 대학생, 취준 초보 |

#### 멘토링 서비스
- 무료 게시판 형태
- 대기업 멘토 68명 (삼성전자, 아모레퍼시픽 등)
- 자소서 만능 검색기

#### 강점/약점
- **강점**: 무료, 대기업 멘토
- **약점**: 게시판 형태 (1:1 아님), 게임업계 멘토 부족

### 2.5 F-Lab

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 개발자 1:1 심화 멘토링 (부트캠프) |
| 타겟 고객 | 주니어 개발자, 이직 희망자 |

#### 가격 정책
| 과정 | 가격 | 기간 |
|------|------|------|
| 백엔드 멘토링 | **498만원** | 4~6개월 |
| 프론트엔드 멘토링 | **586만원** | 4~6개월 |

#### 서비스 특징
- 2:1 소수 정예 (멘티 2명 + 멘토 1명)
- 주 1회 온라인 멘토링
- 네이버, 카카오, 엔씨소프트 출신 멘토
- 이력서 첨삭, 코드 리뷰, 모의 면접

#### 강점/약점
- **강점**: 깊이 있는 기술 멘토링, 취업 성과
- **약점**: 고가 (500만원대), 장기 코스만 제공

> 출처: [F-Lab 멘토링](https://f-lab.kr/reviews)

### 2.6 인프런 멘토링

#### 개요
| 항목 | 내용 |
|------|------|
| 서비스 설명 | 개발자/디자이너 1:1 멘토링 마켓플레이스 |
| 타겟 고객 | 개발자, IT 직군 |

#### 가격 정책
- 멘토가 직접 가격 설정
- 인프런 수수료 0% (결제수수료만 부과)
- 무료 ~ 수십만원까지 다양

#### 서비스 특징
- 강의 플랫폼과 연계
- 커리어 상담, 코드 리뷰, 포트폴리오 리뷰
- 게임 프로그래머 멘토링도 일부 존재

#### 강점/약점
- **강점**: 개발자 특화, 강의 연계
- **약점**: 게임 업계 멘토 소수

> 출처: [인프런 멘토링](https://www.inflearn.com/mentors)

- 게임업계 채용 정보는 이미 있음
- **멘토링은 부재** → ITup 차별화 포인트

## 4. 경쟁 우위 분석

### 4.1 ITup 차별화 포인트

| 차별점 | 설명 | 경쟁사 대비 |
|--------|------|-------------|
| **게임 업계 유일** | 게임 전문 멘토링 플랫폼 없음 | 원티드, 인프런은 IT 일반 |
| **적정 가격** | 3~10만원 (1회 상담) | 원티드 고가, 잇다 무료 |
| **실시간 상담** | 화상/음성 예약 | 잇다는 텍스트만 |
| **멘토 보상** | 수익 배분 | 잇다는 재능기부 |
| **커피챗 대체** | 종료된 시장 진입 | 공백 상태 |

### 4.2 경쟁 열위 요소

| 열위점 | 대응 전략 |
|--------|----------|
| 멘토 풀 부족 | 대형 게임사 현직자 집중 영입 |
| 브랜드 인지도 낮음 | 게임 커뮤니티 타겟 마케팅 |
| 채용 연계 없음 | Phase 3에서 게임사 제휴 |

## 5. 시사점 및 전략 제언

### 5.1 핵심 인사이트

1. **틈새시장 존재**: 게임업계 특화 멘토링은 ITup이 유일
2. **가격 포지셔닝**: 무료(잇다)와 고가(원티드) 사이 공략
3. **커피챗 이탈 수요**: 종료된 서비스 사용자 흡수 기회
4. **멘토 확보 중요**: 모든 경쟁사의 공통 과제

### 5.2 권장 전략

| 단계 | 전략 | 참고 경쟁사 |
|------|------|-------------|
| **진입** | 저가(3만원~)로 멘토-멘티 확보 | 잇다의 무료 전략 |
| **차별화** | 게임업계 특화 + 실시간 상담 | 원티드의 IT 특화 |
| **수익화** | 상담료 수수료 + 프리미엄 서비스 | 원티드 모델 |
| **확장** | B2B 게임사 제휴, 채용 연계 | 원티드, 잇다 참고 |

### 5.3 벤치마킹 포인트

| 경쟁사 | 벤치마킹 요소 |
|--------|--------------|
| 잇다 | 실명 검증 시스템, 대학/기관 제휴 |
| 원티드 | 채용 연계, 합격 보상금 |
| F-Lab | 심층 멘토링 품질, 취업 성과 |
| 인프런 | 멘토 자율 가격제, 강의 연계 |
