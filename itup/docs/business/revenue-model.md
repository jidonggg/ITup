## 2. 수수료 구조

### 2.1 플랫폼 수수료

| 항목 | 비율 | 설명 |
|------|------|------|
| 기본 수수료 | **15%** | 상담료에서 플랫폼 취득 |
| 결제 수수료 | **3.5%** | 토스페이먼츠 결제 수수료 |
| 멘토 정산 | **81.5%** | 멘토 실수령액 |

### 2.2 수수료 계산 예시

**30분 상담 (5만원) 기준**
```
상담료:           50,000원
- 플랫폼 수수료:   7,500원 (15%)
- 결제 수수료:     1,750원 (3.5%)
= 멘토 정산:      40,750원 (81.5%)
```

### 2.3 경쟁사 수수료 비교

| 서비스 | 수수료율 | 비고 |
|--------|----------|------|
| 원티드 (채용) | 7% | 연봉 기준 |
| 인프런 멘토링 | 0% | 결제수수료만 |
| 숨고 | 10~20% | 서비스별 상이 |
| **ITup** | **15%** | 적정 수준 |

## 6. BEP (손익분기점)

### 6.1 BEP 분석

```
월 고정비: 52,000원
건당 순수익: 5,750원 (50,000원 × 15% - 결제수수료)

BEP = 52,000 ÷ 5,750 = 약 9건/월
```

### 6.2 BEP 도달 조건

| 지표 | 필요 수치 |
|------|----------|
| 월 최소 상담 | **9건** |
| 활성 멘토 수 | 3명 (월 3건/인) |
| 활성 멘티 수 | 9명 |

**결론**: 멘토 3명, 월 9건 상담으로 손익분기 달성 가능 → **진입 장벽 낮음**

## 7. 수익화 로드맵

### Phase 1: 기반 구축 (현재)
- 상담 수수료 15% 모델
- 멘토 10명 확보 목표
- 월 50건 상담 목표

### Phase 2: 수익 다각화
- 프리미엄 서비스 도입 (이력서, 포트폴리오)
- 패키지 상품 출시
- 멘토 50명 확보

### Phase 3: B2B 확장
- 게임사 채용 연계 (건당 수수료)
- 기업 멘토링 프로그램
- 합격 보상금 제도 (원티드 벤치마킹)
