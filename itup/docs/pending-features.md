## 현재 페이지 목록 (16개)

| 경로 | 설명 |
|------|------|

| `/mentors` | 멘토 전체 목록 |
| `/mypage` | 마이페이지 (탭 UI) |
| `/admin` | 운영자 대시보드 |
| `/faq` | 자주 묻는 질문 |
| `/mentor/register` | 멘토 등록 |

| `/payment/success` | 결제 성공 |
| `/payment/fail` | 결제 실패 |

| `/terms` | 이용약관 |
| `/privacy` | 개인정보처리방침 |

## 기술 스택

- **Frontend**: Next.js 16.1.5, React 19.2.3, TypeScript
- **Styling**: Tailwind CSS
- **Backend/DB**: Supabase (PostgreSQL, Auth)
- **결제**: TossPayments SDK
- **배포**: Vercel (예정)
