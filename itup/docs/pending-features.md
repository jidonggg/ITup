## 기술 스택

- **Frontend**: Next.js 16.1.5, React 19.2.3, TypeScript
- **Styling**: Tailwind CSS
- **Backend/DB**: Supabase (PostgreSQL, Auth, RLS)
- **결제**: TossPayments SDK
- **이메일**: Resend API
- **배포**: Vercel (https://itup.vercel.app)
