## 1. 즉시 수정 필요 (MVP)

### 1.1 "모든 멘토 보기" 버튼
- **위치**: Mentors 섹션 하단
- **현재 상태**: 클릭해도 반응 없음
- **필요 작업**: /mentors 페이지 생성 및 연결

#### 결정 필요 사항
- [ ] **Q1. 멘토 목록 페이지 기능 범위**
  - A) 단순 목록 (카드 나열 + 페이지네이션)
  - B) 필터링 포함 (회사, 기술스택, 상담유형)
  - C) 검색 + 필터링 + 정렬

---

### 1.2 "멘토 둘러보기" 버튼
- **위치**: CTA 섹션
- **현재 상태**: 클릭해도 반응 없음
- **권장 조치**: #mentors 섹션으로 스크롤 이동
- **결정 필요**: 없음 (바로 적용 가능)

---

### 1.3 "소개 영상 보기" 버튼
- **위치**: Hero 섹션
- **현재 상태**: 클릭해도 반응 없음

#### 결정 필요 사항
- [ ] **Q2. 소개 영상 처리 방안**
  - A) 영상 제작 후 모달로 재생 (YouTube/Vimeo 임베드)
  - B) 별도 소개 페이지로 이동
  - C) **버튼 임시 숨김** (영상 준비 전까지)
  - D) 버튼 완전 삭제

---

### 1.4 Pricing 버튼들 (3개)
- **위치**: Pricing 섹션
- **버튼**: "시작하기", "가장 인기 있는 플랜", "프리미엄 시작"
- **현재 상태**: 클릭해도 반응 없음

#### 결정 필요 사항
- [ ] **Q3. 결제 전 임시 처리 방안**
  - A) 클릭 시 "준비 중입니다" 토스트 메시지
  - B) 클릭 시 무료 상담 신청 모달 열기
  - C) 클릭 시 "출시 알림 받기" 이메일 수집 모달
  - D) 버튼 비활성화 (disabled) + "Coming Soon" 표시

- [ ] **Q4. 결제 시스템 방식 (Phase 3)**
  - A) 선결제 (상담 확정 전 결제)
  - B) 후결제 (상담 완료 후 결제)
  - C) 구독제 (월 정기 결제)
  - D) 건당 결제 + 구독 혼합

## 4. 권장 의견 (기획자)

### 즉시 적용 권장
1. **"멘토 둘러보기"** → `#mentors` 스크롤 (5분 작업)
2. **"소개 영상 보기"** → 임시 숨김 권장 (C)
3. **Pricing 버튼** → 무료 상담 모달 열기 권장 (B)
   - 이유: 전환율 유지, 사용자 이탈 방지

### MVP 우선순위
1. `/mentors` 페이지 (필터링 포함 - B 권장)
2. 이용약관/개인정보처리방침 (법적 필수)
3. FAQ 페이지

### 숨김/삭제 권장
- 기업 서비스, 채용, 블로그, 언론 보도 → MVP에서 숨김
- 소셜 링크 → 운영 계획 없으면 숨김
