# 멘토 섭외 메시지 템플릿

## 1차 접촉 (카톡/문자)

### A. 친한 지인용
```
야 [이름]아!

나 요즘 게임업계 멘토링 플랫폼 만들고 있거든.
취준생들이 현직자한테 커피챗 받는 서비스야.

혹시 멘토로 참여할 생각 있어?
건당 3.5만원이고 월 1-2번 30분 정도면 돼.

관심 있으면 얘기해줘!
```

### B. 선후배/동료용
```
안녕하세요 [이름]님!

다름이 아니라 제가 게임업계 취준생 대상
멘토링 플랫폼(ITup)을 준비하고 있는데요.

현직자분들께서 30분 커피챗으로
후배들 상담해주시면 건당 3.5만원 드립니다.

혹시 관심 있으시면 간단히 설명드려도 될까요?
부담 없이 거절하셔도 괜찮습니다!
```

### C. 오랜만에 연락하는 지인용
```
안녕하세요 [이름]님, [본인이름]입니다!
오랜만에 연락드려요.

다름이 아니라 요즘 게임업계 멘토링 서비스를
만들고 있는데, [이름]님이 떠올라서 연락드렸어요.

현직자분들이 취준생들 커피챗 해주시는 건데,
혹시 관심 있으시면 잠깐 설명드려도 될까요?
```

## 2차 설명 (관심 표현 시)

### 전체 설명
```
[ITup 멘토 안내]

1. 수익
   - 상담 1건당 35,000원 (30분 기준)
   - 매월 말 계좌 입금

2. 시간 투자
   - 본인이 원하는 시간대만 오픈
   - 월 1-2건도 OK (강제 없음)

3. 상담 방식
   - 온라인: Zoom/Google Meet
   - 오프라인: 원하시면 가능

4. 상담 내용
   - 커리어 상담 (취업, 이직)
   - 이력서/포트폴리오 리뷰
   - 모의면접 (선택)

5. 초기 멘토 혜택
   - 파운딩 멘토 배지 (영구)
   - 첫 3개월 수수료 0%
   - 플랫폼 방향 피드백 반영

등록은 5분이면 끝나요!
→ itup.vercel.app/mentor/register
```

### 짧은 버전
```
간단 요약:
- 30분 상담 = 3.5만원
- 시간은 본인이 정함
- 온라인으로 진행
- 등록 5분 컷

링크: itup.vercel.app/mentor/register
```

## 추가 설득 멘트

### "시간 없어요" 대응
```
완전 이해해요!
사실 월에 1-2번, 30분이면 되거든요.
점심시간이나 퇴근 후 30분 정도만 내주시면 돼요.
일단 등록해두시고 여유 있을 때만 받으셔도 됩니다!
```

### "부담돼요" 대응
```
전혀 거창한 게 아니에요!
그냥 후배가 "형/누나 커피 한잔 하면서 얘기 좀요"
하는 느낌이에요.
경험 공유만 해주셔도 취준생들한테 큰 도움이 됩니다.
```

### "돈은 됐고..." 대응
```
아 그러시면 재능기부로도 가능해요!
금액은 취준생 부담 낮추는 데 쓰겠습니다.
마음 편하게 참여해주시면 감사하죠!
```

### "생각해볼게" 대응
```
네 천천히 생각해보세요!
혹시 궁금한 거 있으시면 편하게 물어봐주시고,
나중에라도 괜찮으시면 연락주세요~
```

## 등록 완료 후 안내

```
등록 감사합니다!

[다음 단계]
1. 회사 이메일 인증 (선택이지만 권장)
   → 인증 배지가 붙어서 신뢰도 UP

2. 프로필 보완
   → 자기소개 작성하시면 매칭률 UP

3. 첫 상담 전 온보딩
   → 제가 10분 정도 플랫폼 사용법 안내드릴게요
   → 언제 통화 가능하세요?

질문 있으시면 편하게 연락주세요!
```

```
현직자분 계시면 소개 부탁드려도 될까요?

추천해주시면:
- 추천인(본인): 1만원 지급
- 피추천인: 1만원 지급
(피추천인 첫 상담 완료 시)

부담 없이 생각나시는 분 있으면 알려주세요!
```
