## 회의 목적

멘토-멘티 전체 사이클이 처음부터 끝까지 정상 동작하도록 점검하고,
기능/디자인/사업 관점에서 개선 사항을 도출하여 우선순위를 결정한다.

## 1. 현재 상태 종합 평가

### 1-1. 전체 아키텍처
- **스택:** Next.js 14 + Supabase + TossPayments + Tailwind CSS v4
- **페이지:** 31개, **API:** 23개, **컴포넌트:** 40개+
- **보안:** HTTP 헤더, Rate Limiting, 타이밍 안전 비교 등 기반 탄탄
- **SEO:** sitemap, robots, JSON-LD, OG 이미지 등 기술 SEO 완비

### 1-2. 핵심 문제: "이중 시스템" 공존

모든 팀에서 공통 지적한 **가장 심각한 문제**:

```
┌─────────────────────────────────────────────────────────┐
│           v1 (레거시)         vs        v2 (신규)        │
├─────────────────────────────────────────────────────────┤
│ ConsultModal                    /booking/[productId]     │
│ consultations 테이블             bookings 테이블          │
│ PRICES 고정가                    멘토 자율 가격            │
│   (15,000/39,000/59,000)         (PRICE_LIMITS 범위)     │
│ Pricing 컴포넌트에서 사용         멘토 상세에서 사용         │
│ PRODUCT_PRICES로 결제 검증       결제 검증 미연결           │
│ ProductType: coffee/resume/     ProductType: coffee_chat/ │
│   interview                       document_review/...    │
└─────────────────────────────────────────────────────────┘
```

**결과:** 사용자가 보는 가격과 실제 결제 검증 가격이 불일치하여 결제 실패 가능

## 2. 팀별 핵심 발견 사항

### 기획팀 (UX기획 / 서비스기획 / 콘텐츠기획)

| 발견 | 심각도 | 설명 |
|------|--------|------|
| 이중 예약 시스템 | Critical | ConsultModal(홈) vs /booking(멘토상세) 동선 분리 |
| 소셜 로그인 미구현 | High | 카카오/네이버/Google 버튼 존재하나 모두 disabled |
| 온보딩 반복 리다이렉트 | Medium | 스킵한 사용자가 재방문 시 반복 |
| 무료체험 배너 자격 미검증 | Medium | 이미 체험 완료한 사용자에게도 노출 |
| Pricing CTA → 레거시 플로우 | High | 홈 가격표에서 레거시 ConsultModal로 연결 |

### 사업팀 (수익모델 / 성장전략 / 시장분석)

| 발견 | 심각도 | 설명 |
|------|--------|------|
| 파운딩 멘토 0% 수수료 미구현 | Critical | 모집 페이지에서 홍보 중이나 코드에 없음 |
| 가격 체계 이중화 | High | 레거시 고정가 vs 멘토 자율가 공존 |
| 전환 추적 localStorage 한정 | High | 서버사이드 분석 서비스 미연동 |
| 콘텐츠 SEO 부재 | Medium | 블로그/가이드 페이지 없음 |
| 번들 상품 미구현 | Medium | 사업팀 설계 완료, 코드 미반영 |

### 개발팀 (프론트엔드 / 백엔드 / 보안)

| 발견 | 심각도 | 설명 |
|------|--------|------|
| 결제 금액 검증 고정가 한정 | Critical | payment/confirm이 PRODUCT_PRICES 상수로만 검증 |
| 세션 ID 형식 불일치 | High | Analytics UUID 검증 vs 실제 생성 형식 불일치 |
| /mentor/recruit dead code | High | next.config.ts에서 /mentor/apply로 리다이렉트 |
| 할인 코드 사용량 in-memory | Medium | 서버리스 cold start 시 리셋 |
| ProductType 이름 충돌 | Medium | payment/types vs supabase/types 충돌 |

### 디자인팀 (UI / UX / 브랜드)

| 발견 | 심각도 | 설명 |
|------|--------|------|
| 색상 대비 WCAG 미달 | High | --muted 색상 대비 ~3.4:1 (최소 4.5:1) |
| Testimonials 미구현 | High | return null — 소셜 프루프 섹션 부재 |
| 다크모드 미지원 | Medium | 2025-26 트렌드 필수 |
| 한국어 폰트 미적용 | Medium | Geist (영문 최적화)만 사용 |
| prefers-reduced-motion 미대응 | Medium | 접근성 법규 대응 필요 |

### QA팀 (기능테스트 / 보안테스트 / 사용성테스트)

| 발견 | 심각도 | 설명 |
|------|--------|------|
| BUG-01: 결제 가격 불일치 | Critical | 표시 가격 ≠ 서버 검증 가격 |
| BUG-07: admin 멘토 거절 시 role="user" | High | 유효하지 않은 role 값 |
| BUG-08: 할인 적용 결제 실패 | Critical | 할인 금액이 서버에 전달 안됨 |
| SEC-02: 알림톡 임의 발송 | High | 인증 사용자가 임의 번호로 발송 가능 |
| UX-03: FAQ 환불 정보 불일치 | High | "전액 환불" 안내 vs 실제 48h/24h 정책 |

## 3. 멘토-멘티 전체 사이클 분석

### 현재 플로우

```
[멘티 플로우]
회원가입 → 온보딩 → 멘토 탐색 → 무료체험 예약 → 세션 → 세션확인
  → 유료 예약 → 결제 → 세션 → 세션확인 → 리뷰 작성

[멘토 플로우]
회원가입 → 멘토 지원(이메일 인증) → 관리자 승인 → 대시보드
  → 예약 확인/거절 → 세션 진행 → 피드백 작성 → 정산 요청

[관리자 플로우]
멘토 승인/거절 → 분쟁 관리 → 환불 처리 → 정산 처리
```

### 끊기는 지점 (사이클 블로커)

| # | 지점 | 원인 | 전 팀 합의 심각도 |
|---|------|------|------------------|
| 1 | **유료 결제** | v1/v2 가격 불일치로 결제 실패 가능 | Critical |
| 2 | **할인 코드 결제** | 할인 적용 금액 서버 전달 경로 없음 | Critical |
| 3 | **멘토 모집 페이지 접근 불가** | next.config.ts 리다이렉트 | High |
| 4 | **파운딩 멘토 정산** | 0% 수수료 약속했으나 15% 부과 | High |
| 5 | **관리자 멘토 거절** | role="user" 잘못된 값 저장 | High |

## 5. 의사결정 결과

### 결정 1: 가격 체계 → **멘토 자율 가격 (v2)로 통합**
- 멘토가 PRICE_LIMITS 범위 내에서 직접 가격 설정
- Pricing 섹션은 "가격대" 표시 방식으로 변경
- v1 고정가(PRICES 상수) 및 티어 배율 시스템 제거

### 결정 2: 레거시 코드 → **즉시 제거**
- ConsultModal, consultations 테이블 참조, v1 가격 상수 모두 삭제
- /booking/[productId] (v2) 플로우로 전면 전환
- Pricing CTA를 /mentors로 변경

### 결정 3: 번들 상품 → **보류**
- 단건 상품 안정화 후 재검토
- 번들 코드 재도입 없이 현재 단건 3종(커피챗/서류리뷰/모의면접) 유지

### 결정 4: 다크모드 → **2주 내 구현 (Phase C)**
- 디자인 트렌드 대응 우선
- globals.css에 다크 팔레트 추가 + Tailwind dark: prefix 활용

## 7. 긍정적 평가 (유지할 부분)

- 결제 보안: 3중 금액 검증, 보상 트랜잭션, 타이밍 안전 비교
- 멘토 인증: 회사 이메일 도메인 검증 (게임사 30+ 도메인)

- 디자인: Glassmorphism, 반응형, 모바일 전용 컴포넌트 4종
- SEO: sitemap, robots, JSON-LD, OG 이미지
- 보안 헤더: HSTS, CSP, X-Frame-Options 등 포괄적 설정
- 코드 품질: TypeScript 타입 시스템, 일관된 한국어 에러 메시지
- CRON: 자동 완료 + 세션 리마인더 구현 완료
