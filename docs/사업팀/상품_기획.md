## 4. 가격 설계 원칙

1. **심리적 마지노선**: 모든 단건 상품 10만원 미만
2. **티어 배율**: 주니어 1.0x, 시니어 1.3x, 리드 1.6x (1000원 단위 반올림)
3. **번들 할인**: 20-30% (번들이 항상 단건보다 이득)
4. **앵커링**: 모의면접 단건 vs 올인원 번들 비교로 번들 전환 유도
5. **진입 장벽 최소화**: 텍스트 5,000원, 커피챗 15,000원 = "점심값 수준"
