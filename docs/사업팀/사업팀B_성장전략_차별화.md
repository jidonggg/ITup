## 2. 멘토 확보 전략

### 2-1. 현황

- 현재 등록 멘토: **0명**
- 목표: **1개월 내 10명, 3개월 내 30명**
- 멘토 모집 메시지 + 트래킹 시트 이미 작성됨 (`docs/mentor-recruitment/`)

### 2-2. 1단계: 직접 네트워크 (1~2주)

| 채널 | 방법 | 목표 |
|------|------|------|
| 개인 인맥 | 게임업계 지인 직접 연락 | 5명 |
| 동문 네트워크 | 게임학과/컴공 동문회 | 3명 |
| 지인 소개 | 등록 멘토의 동료 소개 요청 | 2명 |

**핵심 메시지:** "30분에 ₩29,750, 월 1~2회, 온라인, 파운딩 멘토 뱃지"

### 2-3. 2단계: 커뮤니티 침투 (3~4주)

| 커뮤니티 | 규모 | 접근 방법 |
|----------|------|-----------|
| **인디게임 디스코드** (한국) | 5,000+ | 채널에 멘토 모집 공고 |
| **게임잡 카페** (네이버) | 30,000+ | 멘토 경험담 콘텐츠 작성 |
| **게임 개발자 오픈채팅** (카카오톡) | 다수 | 자연스러운 플랫폼 소개 |
| **게임학과 교수** | - | 학과 취업 지원 프로그램 연계 제안 |
| **게임사 사내 게시판** | - | 내부 추천 유도 (등록 멘토 통해) |

### 2-4. 3단계: 콘텐츠 마케팅 (1~3개월)

| 콘텐츠 | 목적 | 채널 |
|--------|------|------|
| "게임업계 취업 가이드" 시리즈 | 멘티 유입 + SEO | 블로그/브런치 |
| "현직자 인터뷰" 영상 | 멘토 브랜딩 + 신뢰 | 유튜브/인스타 |

| 멘토 직접 작성 칼럼 | 멘토 참여도 + SEO | 플랫폼 내 블로그 |

## 4. 사업 확장 시나리오

### 시나리오 1: 게임업계 깊게 파기 (권장)

```
현재: 1:1 멘토링
  ↓ (3개월)
+ 그룹 멘토링 (3~5명, 저가)
  ↓ (6개월)
+ 게임사별 취업 패키지 (넥슨반, 크래프톤반)
  ↓ (9개월)
+ 게임사 채용 연계 (B2B)
  ↓ (12개월)
+ 게임업계 커리어 플랫폼 (연봉 데이터, 기업리뷰, 멘토링 통합)
```

**장점:** 니치 마켓 장악, 브랜드 파워 구축, 진입 장벽 형성
**리스크:** 시장 규모 한계 (게임업계만)

### 시나리오 2: IT 전체로 확장

```
현재: 게임업계
  ↓ (6개월)
+ IT/소프트웨어 업계
  ↓ (12개월)
+ 전체 테크 업계
```

**장점:** 시장 규모 확대
**리스크:** ADPList/링커리어와 직접 경쟁, 차별화 희석

### 사업팀 B 판단: **시나리오 1 권장**

이유:
1. 게임업계에서 압도적 1등 → 자연스러운 확장 기반
2. "게임업계 = 커피챗" 브랜드 인식 구축이 먼저
3. 게임업계만으로도 연 2만명+ 타겟 풀 존재
4. 확장은 게임업계 장악 후에도 늦지 않음

## 5. B2B 사업 기회

### 5-1. B2B 상품 설계

| 상품 | 타겟 | 가격 | 내용 |
|------|------|------|------|
| **신입 온보딩 패키지** | 게임사 HR | ₩500,000/인 | 입사 3개월 시니어 멘토링 |
| **팀빌딩 멘토링** | 게임 스튜디오 | ₩2,000,000/팀 | 10명 팀 단위 그룹 멘토링 |
| **채용 연계** | 게임사 채용팀 | 연봉 10% | 멘토가 추천한 멘티 채용 시 |
| **기업 교육** | 게임사 교육팀 | 협의 | 커스텀 교육 프로그램 |

### 5-2. B2B 진입 시점

- **지금은 아님.** B2C에서 멘토 30명 + 상담 100건 달성 후
- **이유:** B2B 영업에는 "이미 잘 되고 있다"는 실적이 필수
- **예상 시점:** 런칭 3~6개월 후

## 6. 리텐션 & 네트워크 효과 전략

### 6-1. 멘토 리텐션

| 장치 | 설명 |
|------|------|
| **파운딩 멘토 뱃지** | 초기 멘토 → 영구 특별 뱃지, 수수료 우대 |
| **멘토 리더보드** | 월간 상담 수/평점 기반 순위 → 경쟁 유도 |
| **멘토 수익 대시보드** | 실시간 수익/상담 현황 → 동기 부여 |
| **멘토 네트워킹 이벤트** | 분기별 오프라인 모임 → 소속감 |
| **멘토 레벨 시스템** | 상담 수에 따른 등급 (브론즈→실버→골드→다이아) |

### 6-2. 멘티 리텐션

| 장치 | 설명 |
|------|------|
| **상담 후 액션 플랜** | 멘토가 상담 후 과제 부여 → 다음 상담 유도 |
| **취업 성공 스토리** | 커피챗으로 취업한 사례 → 신규 유입 + 기존 유저 동기 |
| **첫 상담 무료** | 진입 장벽 제거 → 유료 전환 유도 |
| **상담 묶음 할인** | 3회, 5회 묶음 → LTV 향상 |
| **리뷰 인센티브** | 리뷰 작성 시 다음 상담 ₩5,000 할인 |

## 7. 사업팀 B 제안사항

### 즉시 실행 (이번 주)

1. **개인 네트워크 10명 컨택 시작** — 트래킹 시트 활용
2. **게임잡 네이버 카페 가입 + 자연스러운 활동** — 바로 홍보하지 않고 존재감 구축
3. **멘토 모집 랜딩 페이지 기획** — "왜 커피챗 멘토가 되어야 하는가" 설득

### 단기 (1개월 내)

4. **게임학과 3개교 접촉** — 취업 특강 또는 취업 지원 프로그램 연계
5. **"게임업계 취업 가이드" 콘텐츠 3편** — SEO + 유입
6. **첫 상담 무료 정책 시행** — 15분 무료 → 유료 전환

### 중기 (3개월 내)

7. **그룹 멘토링 상품 출시** — 3~5명 그룹, 단가 ₩15,000/인
8. **회사별 취업 패키지** — "넥슨 취업 올인원" 등
9. **리뷰 인센티브 시스템** — 리뷰 + 추천인 보상
