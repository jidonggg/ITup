## 1. 사업팀 A 발표 요약

**핵심 발견:**
- 직접 경쟁자 없음 (게임업계 멘토링 = 블루오션)
- 현재 단건 ₩35,000은 적정 수준
- 구독 플랜 가격이 높고, 차별화 가치가 부족
- 멘토 수수료는 초기 85/15 → 6개월 후 80/20 → 1년 후 75/25 제안
- 손익분기점: 월 16건 상담 (매우 낮음)

**주요 제안:** 구독 가격 인하, 첫 상담 무료, 멘토 자율 가격 일부 도입

---

## 2. 사업팀 B 발표 요약

**핵심 발견:**
- 커피챗의 최대 무기: 회사이메일 인증 + 게임업계 유일 특화
- 콜드스타트 해결이 최우선 (멘토 0명 → 10명)
- 연 타겟 풀 2만명+ (게임학과 졸업생, 이직 희망자, 비전공 진입자)
- B2B는 B2C 실적 확보 후 (3~6개월 후)
- 확장 방향: 게임 깊게 파기 > IT 전체 확장

**주요 제안:** 개인 네트워크로 멘토 10명 선확보, 게임학과/커뮤니티 공략, 콘텐츠 SEO

## 3. 기획팀 피드백

### 동의한 사항
- 구독 가격 인하 필요 (현재 Basic ₩99,000은 진입 장벽)
- 첫 상담 무료는 전환율에 큰 효과 기대
- 멘토 수수료 85/15 초기 전략 합리적
- 게임업계 깊게 파기 (시나리오 1) 동의

### 기획팀이 추가 제기한 이슈
1. **온보딩 플로우 없음** — 첫 방문자가 "뭘 해야 하는지" 모름
2. **멘토 모집 랜딩 페이지 없음** — 현재 등록 폼만 존재
3. **"왜 유료인가" 설득 부족** — ADPList가 무료인데 왜 돈 내야 하는지
4. **모바일 최적화 부족** — 타겟 유저(20대)가 모바일 비중 높음

### 기획팀 제안
- 멘티 온보딩: 가입 → 관심 직군 선택 → 추천 멘토 → 첫 상담 무료
- 멘토 모집 전용 페이지: 수익, 시간, 방법, 파운딩 멘토 혜택 강조
- "인증된 현직자"를 전면에 — 무료 서비스와의 차별점

---

## 4. 개발팀 실행 가능성 검토

### 현재 기술 상태
- MVP 완성 (인증, 결제, 상담, 리뷰 전체 작동)
- Supabase + Next.js + TossPayments 안정적
- TypeScript 빌드 에러 없음

### 제안별 기술 난이도

| 제안 | 난이도 | 비고 |
|------|--------|------|
| 구독 가격 변경 | 쉬움 | constants.ts 수정만으로 가능 |
| 첫 상담 무료 | 중간 | 결제 플로우 분기 + DB 필드 추가 |
| 멘토 자율 가격 | 중간 | mentors 테이블에 custom_price 필드, UI 수정 |
| 온보딩 플로우 | 중간 | 새 페이지 + 프로필 스텝 위저드 |
| 멘토 모집 랜딩 | 쉬움 | 새 정적 페이지 |
| 그룹 멘토링 | 높음 | 새 상담 유형, 다인 결제, 스케줄링 |
| B2B 상품 | 높음 | 기업 계정, 대시보드, 대량 결제 |
| 리뷰 인센티브 | 쉬움 | 쿠폰/포인트 시스템 |

### 개발팀 의견
- 1주 내 가능: 가격 변경, 멘토 모집 랜딩, 리뷰 인센티브
- 2주 내 가능: 첫 상담 무료, 온보딩 플로우
- 1개월 내 가능: 멘토 자율 가격, 그룹 멘토링
- B2B는 별도 프로젝트로 분리 필요

## 5. 전체 토론 결과

### 논점 1: 구독 vs 단건 — 어디에 집중할 것인가?

| 의견 | 팀 | 근거 |
|------|-----|------|
| 단건 집중 | 사업팀 A, 개발팀 | 초기에는 진입 장벽 낮추는 게 핵심 |
| 구독도 유지 | 사업팀 B | 구독은 LTV 확보 수단, 버리면 안 됨 |
| 구독 가격 인하 후 유지 | 기획팀 | 구독 존재 자체가 "프리미엄 서비스" 인식 부여 |

**합의:** 단건 중심으로 운영하되, 구독은 가격 인하하여 유지. 구독 전환 유도는 3개월 후부터 본격화.

### 논점 2: 첫 상담 무료 — 15분 vs 30분?

| 의견 | 팀 | 근거 |
|------|-----|------|
| 15분 무료 | 사업팀 A | 맛보기로 충분, 멘토 부담 적음 |
| 30분 무료 | 사업팀 B | 15분은 의미 있는 대화 어려움 |
| 15분 무료 | 기획팀 | 30분은 유료와 동일 → 유료 전환 동기 약화 |
| 15분 무료 | 개발팀 | 구현 동일, 정책 문제 |

**합의:** 첫 상담 15분 무료. 이후 유료 30분 상담으로 전환 유도.

### 논점 3: 확장 방향 — 게임 깊게 vs IT 넓게?

**만장일치: 게임업계 깊게 파기.**

근거:
- "게임업계 = 커피챗" 브랜드를 먼저 만들어야 함
- 넓게 가면 ADPList/링커리어와 직접 경쟁 → 불리
- 게임업계만으로도 2만명+ 타겟 → 충분한 시장
- 확장은 게임업계 장악 후에도 가능

### 논점 4: 멘토 수수료 — 얼마?

**합의: 초기 85/15 (멘토 85%, 플랫폼 15%)**

- 파운딩 멘토는 첫 3개월 수수료 0% (멘토 100%)
- 이후 85/15로 전환
- 6개월 후 상황 보고 80/20 전환 검토

### 논점 5: 우선 개발 항목

전 팀 투표 결과:

| 순위 | 항목 | 표 |
|------|------|---|
| 1 | 멘토 모집 랜딩 페이지 | 전원 |
| 2 | 첫 상담 무료 기능 | 전원 |
| 3 | 구독 가격 인하 | 사업A, 기획 |
| 4 | 멘티 온보딩 플로우 | 기획, 사업B |
| 5 | 그룹 멘토링 | 사업B |

## 6. 최종 합의 사항

### 가격 정책 확정

| 상품 | 변경 전 | 변경 후 | 비고 |
|------|---------|---------|------|
| 첫 상담 | 없음 | **무료 (15분)** | 신규 |
| 단건 상담 | ₩35,000/30분 | **₩35,000/30분** | 유지 |
| Basic | ₩99,000/월 | **₩59,000/월** | 인하 |
| Pro | ₩199,000/월 | **₩129,000/월** | 인하 |
| Premium | ₩399,000/월 | **폐지** | 초기에 불필요 |

### 수수료 정책 확정

| 구간 | 멘토 | 플랫폼 |
|------|------|--------|
| 파운딩 멘토 (첫 3개월) | 100% | 0% |
| 0~6개월 | 85% | 15% |
| 6~12개월 | 80% | 20% |
| 12개월+ | 75% | 25% |

### 사업 방향 확정

1. **게임업계 깊게 파기** (IT 확장은 12개월 후 재논의)
2. **B2C 먼저, B2B는 3~6개월 후**
3. **멘토 확보가 최우선** (콜드스타트 해결)
