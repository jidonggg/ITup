| **멘토 자율 가격** (MentorCruise형) | 시장이 가격 결정 | 가격 편차 큼, 초기 혼란 | ★★★ |
| **분당 과금** (Clarity형) | 초저가 진입 가능 | 기술 구현 복잡, 통화 품질 이슈 | ★★ |

## 3. 커피챗 현재 가격 경쟁력 분석

### 3-1. 현재 가격 체계

| 상품 | 가격 | 시간당 환산 |
|------|------|-------------|
| 단건 상담 (할인가) | ₩35,000/30분 | ₩70,000/시간 |
| Basic | ₩99,000/월 (2회 50분) | ₩59,400/시간 |
| Pro | ₩199,000/월 (4회 60분) | ₩49,750/시간 |
| Premium | ₩399,000/월 (무제한) | 사용량에 따라 다름 |

### 3-2. 시장 대비 포지셔닝

```
저가                                                          고가
├────────┼────────────┼──────────────┼───────────────┤
₩10,000  ₩30,000     ₩50,000       ₩100,000       ₩200,000+
링커리어   캐치       ★커피챗 단건    MentorCruise    전문 컨설팅
                     (₩35,000)      (월 $150~)
```

### 3-3. 가격 문제점

1. **단건 ₩35,000은 적정 수준** — 한국 멘토링 시장 중간대, 게임업계 전문성 프리미엄 반영
2. **Basic ₩99,000은 높음** — 월 2회치고 비쌈. 링커리어/캐치 무료~₩30,000과 비교 시 허들
3. **Premium ₩399,000은 비현실적** — 초기 서비스에서 이 가격대 구독자는 거의 없음
4. **구독 플랜의 가치 제안이 약함** — 단건과 구독의 차이가 "횟수"뿐. 구독만의 독점 가치 필요

## 4. 멘토 수수료 구조 분석

### 4-1. 업계 기준

| 플랫폼 | 멘토 수취율 | 플랫폼 수수료 |
|--------|-------------|---------------|
| MentorCruise | 80% | 20% |
| Codementor | 80% | 20% |
| 탈잉 | 70~80% | 20~30% |
| Clarity.fm | 85% | 15% |
| **업계 평균** | **78%** | **22%** |

### 4-2. 커피챗 수수료 제안

**초기 (0~6개월):** 멘토 85% / 플랫폼 15%
- 이유: 멘토 확보가 최우선. 높은 수취율로 유인
- ₩35,000 단건 기준: 멘토 ₩29,750 / 플랫폼 ₩5,250

**성장기 (6~12개월):** 멘토 80% / 플랫폼 20%
- 플랫폼 가치가 증명된 후 업계 표준으로 전환
- ₩35,000 기준: 멘토 ₩28,000 / 플랫폼 ₩7,000

**안정기 (12개월+):** 멘토 75% / 플랫폼 25%
- 충분한 멘티 유입 → 멘토에게 플랫폼 가치 입증
- ₩35,000 기준: 멘토 ₩26,250 / 플랫폼 ₩8,750

## 6. 사업팀 A 제안사항

### 즉시 실행 (이번 주)

1. **멘토 수수료 85/15로 확정** — 초기 멘토 확보용
2. **구독 가격 하향 조정**
   - Basic: ₩99,000 → ₩59,000 (월 2회)
   - Pro: ₩199,000 → ₩129,000 (월 4회)
   - Premium: 폐지 또는 ₩249,000으로 인하
3. **첫 상담 무료 도입** — 15분 무료 체험 상담 → 전환율 극대화

### 단기 (1개월 내)

4. **구독 차별화 가치 추가**
   - 구독자 전용: 멘토 직접 선택, 멘토 커피챗 기록 열람, 이력서 템플릿
   - 구독자만 사용 가능한 "긴급 상담" (24시간 내 배정)
5. **멘토 자율 가격 일부 도입** — 기본가 ₩35,000 + 멘토별 추가금 허용 (상한 ₩100,000)

### 중기 (3개월 내)

6. **B2B 상품 설계** — 게임사 신입 온보딩 패키지 (5인 이상 단체 할인)
7. **수익 다각화** — 멘토 콘텐츠(블로그/영상) 유료화 검토
